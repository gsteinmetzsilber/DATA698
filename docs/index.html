Automated essay scoring

Grade it yourself

Read a student's essay and score it from 1 to 6 with the rubric the human raters used. Then see what two raters and a fine-tuned language model gave it.

The essays

These essays were drawn at random from the held-out test essays in set 1 of the ASAP automated essay scoring dataset (Hewlett Foundation, 2012). They are persuasive letters written by grade 8 students, and each was scored from 1 to 6 by two human raters.

The model

Llama 3 8B Instruct, fine-tuned with QLoRA on about 2,500 other persuasive essays from the same dataset. It was trained to predict each rater separately, and it gave both raters the same score on every one of the test essays, so it appears here once.
